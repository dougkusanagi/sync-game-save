# 2.0.0 — 2026-11-15

## Alterado

- O aplicativo passa a ser feito em Go com Wails, no lugar de Rust com Tauri. A biblioteca, o catálogo, os saves e os temas continuam os mesmos e são lidos sem conversão; a pasta de dados é a mesma de antes em cada sistema.
- A atualização do app usa um novo canal, com assinatura própria. Quem instalou o 1.1.0 recebe o instalador da versão Go pelo atualizador antigo.
- O instalador do Windows continua por usuário e na mesma pasta, e agora vem em português.
- A tela Sobre mostra o número do build (commit e data) também na versão Go.

## Corrigido

- O controle (Xbox) é lido uma só vez; no Linux, a leitura passa a usar os dispositivos de entrada do sistema.
- No Linux, os dados continuam em `~/.local/share/com.syncgamesave.app`, como na versão anterior.
